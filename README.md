# Web de Kairo's

Páginas de la web de Kairo's Intelligence Agency.

- index.html: página de enlaces (la que va en la bio de Instagram y TikTok)
- stands-nfc.html: página de los stands NFC de reseñas Google
- reventa.html: página para revendedores
- styles.css: colores y estilos compartidos de stands-nfc.html y reventa.html
- img/: fotos del producto

Busca la palabra EDITAR dentro de los archivos para ver qué textos hay que completar (precios, envíos, etc.).
